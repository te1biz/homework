## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/te1biz/homework.git
```
2. Установите зависимости:
```
poetry install
```
## Использование:

1. filter by state -
Фильтрует список словарей по значению ключа
2. sort by date - 
сортирует список по дате
