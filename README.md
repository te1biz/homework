# Обработка банковских операций (Homework)

Учебный проект на Python для обработки, фильтрации и анализа банковских транзакций. Проект поддерживает интерактивное взаимодействие через консольное меню, фильтрацию и сортировку операций, поиск по описанию и категориям, генераторы, маскировку данных, а также чтение финансовых операций из JSON-, CSV- и XLSX-файлов.

## Функционал проекта

### Главное меню (`main.py`)

Интерактивный интерфейс командной строки, который объединяет всю функциональность:
- Выбор источника данных (JSON, CSV или XLSX).
- Фильтрация по статусу транзакции (`EXECUTED`, `CANCELED`, `PENDING`).
- Настраиваемая сортировка по дате (по возрастанию / по убыванию).
- Фильтрация по валюте (например, только рублевые транзакции).
- Поиск транзакций по ключевому слову в описании.
- Форматированный вывод результатов с маскировкой счетов и карт.

### Обработка и сортировка данных (`src.processing`)

- **`filter_by_state`** — фильтрует список транзакций по значению ключа `state`. По умолчанию используется статус `EXECUTED`.
- **`sort_by_date`** — сортирует транзакции по дате (по умолчанию — по убыванию, от новых к старым).

### Поиск и категории (`src.search` / `src.processing`)

- **`search_transactions`** — поиск транзакций по заданной подстроке в поле описания (`description`).
- **`count_transactions_by_category`** — подсчет количества операций по категориям расходов.

### Маскировка данных (`src.masks`)

Функции для маскировки номеров банковских карт и счетов, а также форматирования даты операции.
